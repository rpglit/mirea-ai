## 1. Цель и объём

Цель 1 — уверенное решение ВСЕХ 71 задания каталога MATERIALS_ANALYSIS §3 (PN 40,
LSS 23, FA 8) в формате и терминологии методички: отчёт «Дано / Найти / Решение /
Ответ» + пояснение своими словами (D-041, D-044).
Цель 2 — любые аналогичные задания трёх предметных областей (D-044):
- PN (семинары 1–8): классические / приоритетные / временные / ингибиторные / цветные
  сети; моделирование систем; матричный способ; универсальная машина Минского.
- LSS (семинары 9–12): ОДУ с НУ, весовая функция, передаточная функция, АЧХ/ФЧХ,
  11 стандартных звеньев, пространство состояний.
- FA (семинары 13–15): автоматы без выходного преобразователя / Мура / Мили,
  3 способа задания, моделирование слов, сравнение, эквивалентность, задания семинара 15.
Не в объёме: лекции/обучение, свободное редактирование сети после разбора
(исключение — «кандидат-сеть» для PN-02). API раунда 1 ломать можно (D-041);
UI полностью русский, фронтенд — Vue 3 + Vite + Cytoscape (D-042).

## 2. Глоссарий

Используется глоссарий MATERIALS_ANALYSIS §5 (77 терминов: PN 29, LSS 30, FA 18);
в UI, API и отчётах — только эти термины; нет русского эквивалента → русский +
английский в скобках (напр., «k-ограниченная (k-bounded)»). Шкала живости L0–L4
сохраняется как детализация, вердикт по классификации методички:
«живая / тупиковая / частичнотупиковая» (GAP §5, BUG-4).
Ключевые 15: сеть Петри S=(P,T,I,O,µ); позиция; переход; маркировка; метка; разрешённый
переход; срабатывание (запуск); конфликт; живая сеть; тупиковая сеть;
частичнотупиковая сеть; k-ограниченная сеть; безопасная сеть; консервативная сеть; приоритет Pr t.
