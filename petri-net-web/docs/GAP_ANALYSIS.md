## 5. Терминология (ключевые расхождения; полные таблицы — GAP_BACKEND §4, GAP_UI §4)

| Приложение | Методичка | Оценка |
|---|---|---|
| «активные переходы» / `active_transitions` / «enabled» | «разрешённый переход» | расхождение |
| «Шаг» / `fire` | «срабатывание (запуск) перехода» | расхождение |
| Живость L0–L4 (попереходная шкала) | живая / тупиковая / частичнотупиковая (классификация сети) | расхождение (главное); соответствие: живая ⇔ L4, тупиковая ⇔ тупики≠∅, частичнотупиковая — аналога нет |
| «Без тупиков (deadlock-free)» | «тупиковая сеть» (свойство) | подача через двойное отрицание |
| «мёртвые переходы», «Обратимость (home state)», «Покрываемость (Кэрп–Миллер)» | — (нет терминов) | app-специфично (допустимо как дополнение) |
| «Ограничена (bounded)» + «Глобальная k» | «k-ограниченная сеть» | смысл есть, слово «k-ограниченная» нет |
| — | «консервативная сеть», «конфликт», «принцип максимального параллелизма», «приоритет Pr t», «временные сети», «ингибиторная дуга», «цветные сети», «матричный способ (W±, v(σ))», «минимальная маркировка» | отсутствуют (нет функций) |
| «Граф достижимости», «маркировка», «позиция/переход», text-нотация S=(P,T,I,O,µ) | те же | совпадает (text-грамматика — дословно методичка, проверено) |

Доп. качество кода: docstring `properties.py:190` содержит устаревший якорь
«L3» для эталонной сети (факт и лог — L1).

## 6. Приоритеты (порядок Фазы 4)

1. **4.4 properties (быстрые дополнения, независимы от UI-рефактора):**
   консервативность (Σвх(t)=Σвых(t)); µmin (М6); вердикты
   «живая/тупиковая/частичнотупиковая» поверх L-шкалы (сохранить L-шкалу как
   детализацию); вывод W−/W+/W и v(σ) (М7, в отчёт/эндпоинт). Закрывает
   10 из 14 «частичных» PN-задач (консервативность — 8, W± — PN-18/35);
   оставшиеся 4 (PN-02 синтез, PN-10/30 приоритеты, PN-15 τ) — п.2.
2. **4.2 core + 4.1 parser: расширенные модели** — ингибиторные дуги (PN-33),
   приоритеты Pr t (PN-10, 30), временные сети τ (PN-15, 32), цветные сети
   (PN-36/37 — по A-21), параллельное срабатывание (PN-07, PN-02).
3. **4.5 solvers:**
   - модуль **LSS** (sympy в контейнере): ОДУ+НУ (LSS-01…05), весовая функция
     (06, 07, 17…20), передаточная+АЧХ/ФЧХ (08…16), пространство состояний
     (21…23, + LSS-14); отчёты в формате методички («Дано/Найти/Решение/Ответ»);
   - модуль **FA**: модель A=<P,S,s0,φ[,W,ψ]>, три способа задания, моделирование
     слова по тактам (01…05), Мура→Мили (06), задания 15 (07, 08);
   - решатели PN: готовые отчёты по каждому TASK-PN-NN (граф+разрешённые+цепочки+
     свойства+матрицы+µmin) — «экран Задание из практикума».
4. **4.6 api:** эндпоинты решателей (`POST /solve` per TASK-ID), русские
   сообщения об ошибках (BUG-8), имена сессий (BUG-9), лимит списка сессий.
5. **4.7 ui (пересборка на Vue 3 + Vite + Cytoscape по D-042):** закрывает
   BUG-1…BUG-7, BUG-10 (новые компоненты: экспорт PNG, подписи дуг, подсветка
   текущего узла и активных переходов, клик-по-переходу, кликабельная история,
   валидация формы), BUG-4 (панель свойств по глоссарию), экран «Задание из
   практикума» (выбор TASK-XX → данные → «Решить» → отчёт методички),
   визуализация автоматов (графы F-схем) и LSS-отчётов (формулы, АЧХ/ФЧХ).
6. **5 QA / 6 приёмка:** E2E по каждому TASK-XX; property-тесты на 20+
   случайных сетях/ОДУ/автоматах; эталоны LSS-01…05/14/15 — независимо.

Риск: объём 4.5 (два новых математических модуля) — наибольший; при необходимости
сузить фокус до PN (A-17) пункты 3 (LSS/FA) выносятся в бэклог.
