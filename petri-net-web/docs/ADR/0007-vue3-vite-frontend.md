# ADR-0007: Фронтенд на Vue 3 + Vite + Cytoscape.js

Status: Принята (08.10.2026, раунд 2)

## Контекст

Фронтенд раунда 1 — vanilla JS (8 модулей, ~1500 строк) + вендорный
Cytoscape (`frontend/vendor/cytoscape.umd.js`, D-036). GAP-анализ (GAP_UI)
нашёл 10 багов, из них critical — мёртвый PNG-экспорт (BUG-1: `cy.png()` в
Cytoscape 3.30.2 без `output` возвращает строку, а код ждёт Promise) и major —
подписи весов дуг, подсветка текущего узла, терминология панели свойств.
Раунд 2 добавляет несколько принципиально новых экранов: «Задание из
практикума» (TaskPicker + формы трёх областей), отчёты решателей (формулы
LSS, таблицы по тактам FA), графы конечных автоматов. Дальнейшая разработка
на наборах DOM-функций без сборки и компонентной модели — дороже, чем
переход (решение пользователя по Q5, D-042: «посовременнее и покрасивее,
но не сильно сложнее»).

## Решение

- Стек: **Vue 3** (Composition API, `<script setup>`) + **Vite**; графы —
  **Cytoscape.js из npm** (вендор отменяется, D-036).
- Сборка — отдельный build stage `node:22-alpine` в `backend/Dockerfile`:
  `npm ci` → `vite build --outDir dist` (`base: "./"`) → `COPY --from=build
  dist /app/static`. Рантайм контейнера без node: FastAPI продолжает отдавать
  API и статику одним процессом (D-015).
- Без vue-router и без Pinia: экранов мало (переключение видов внутри `App`),
  состояние — один reactive store (модуль `store.js`), объект на сессию.
- Формулы в отчётах LSS/PN — HTML + `<sub>/<sup>` по полю `Step.text`;
  KaTeX **не входит** в базовую сборку — поле `Step.latex` зарезервировано в
  контракте отчёта, рендерер добавляется опционально без изменения API.
- Экспорт PNG — только `cy.png({ output: "blob-promise" })` →
  `URL.createObjectURL` (фикс BUG-1 закреплён в e2e).
- Старый `frontend/js/*` и `frontend/vendor/` удаляются; `index.html` —
  Vite-вход. e2e-селекторы переписываются под Vue-DOM (раунд 2).

## Последствия

- +1 build stage и `package.json`/`package-lock.json` в `frontend/`; образ
  `app` собирается дольше, рантайм-образ не растёт (node — только build).
- Версия Cytoscape фиксируется в `package-lock.json`; класс бага «API
  Cytoscape изменился» локализуется (один источник, npm-выпуск).
- BUG-2…BUG-7, BUG-10 закрываются в новых компонентах (подписи дуг,
  подсветка, клик-по-переходу, кликабельная история, валидация формы,
  подсветка разрешённых переходов) — см. §3 ARCHITECTURE.
- Отказ от vue-router: углы вида «открыть сессию по URL» не поддерживаются;
  восстановление сессии — через SessionsPanel (FR-406).
- KaTeX-опция не блокирует Фазу 4: без неё отчёты читаемы (unicode-формулы).
