##### TASK-PN-02 — Сеть 5×2: срабатывания, новая маркировка, достроенная сеть
- Тип: задание. Источник: семинар 1, стр. 15. Черновик: TASK-A-2.
- Условие (цитата): «Задание 2. Построить сеть Петри: S = (P, T, I, O, µ), P = {p1, p2, p3, p4, p5}, T = {t1, t2}, I(t1) = {p1, p2}, O(t1) = {p4}, I(t2) = {p2, p3}, O(t2) = {p5}, µ = (1,1,1,0,0). Определить срабатывание переходов. Изменить маркировку таким образом, чтобы оба перехода могли сработать ровно один раз. Достроить сеть таким образом, чтобы срабатывание переходов было возможно неограниченное число раз.»

- Метод: §7 PN, М2–М4.

##### TASK-PN-05 — Эталонная сеть 6×5 (µ=(7,4,2,5,4,3))
- Тип: задание. Источник: семинар 2 (2-2025), стр. 1, Задание 1; дубль: 13-2024, стр. 2 (Задание 1). Черновики: TASK-A-5, TASK-D-09.
- Условие (цитата): «Задание 1. 1.Построить сеть Петри: S = (P, T, I, O, µ), P = {p1, p2, p3, p4, p5, p6}, T = {t1, t2, t3, t4, t5}, I(t1) = {p1, p1}, O(t1) = {p2}, I(t2) = {p1, p6}, O(t2) = {p3, p3}, I(t3) = {p2}, O(t3) = {p4, p4, p4}, I(t4) = {p2, p3, p4, p4}, O(t4) = {p5, p6}, I(t5) = {p5, p5}, O(t5) = {p1, p3}, µ = (7,4,2,5,4,3). 2.Определить какие переходы разрешены в начальный момент времени. 3.Указать маркировку после однократного последовательного срабатывания переходов.»

## 7. Методы решения (объединённые, как даны в материалах)

### 7.1. PN (Сети Петри)
1. **М1. Аналитическое построение сети из S=(P,T,I,O[,µ])** (1-2025, стр. 6–7). Записать P, T; I(tj), O(tj) (кратность дуг — мультимножествами); µ — вектором; граф: позиции — кружки, переходы — планки, дуги p→t / t→p (кратные — одной стрелкой с числом сверху); метки — точки в кружках.
2. **М2. Проверка разрешённости перехода** (1-2025, стр. 13; 5-2025, стр. 2). tj разрешён ⇔ для всех входных позиций число меток ≥ кратность дуги; матричная форма: w⁻_k ≤ µ (поэлементно).
3. **М3. Срабатывание перехода** (1-2025, стр. 13). µ′ = µ − (входные кратности) + (выходные кратности); повторять, пока есть разрешённые переходы; «Когда не останется ни одного разрешённого перехода, выполнение прекращается».
4. **М4. Итеративный анализ** (1-2025, стр. 10, 14). М3 многократно до остановки/исчерпания числа запусков; фиксировать каждую маркировку (по рисунку на шаг).
5. **М5. Классификация сети** (1-2025, стр. 16–19; 13-2024, стр. 3, 5–6). Проверить по определениям: живая/тупиковая/частичнотупиковая; k-ограниченная (максимум меток по достижимым маркировкам); безопасная (k=1); консервативная (сумма меток постоянна ⇔ на каждом переходе вход=выход). «Для доказательства недостижимости tj из маркировки µ, необходимо перебрать все последовательности переходов…» (13-2024, стр. 1) — перебор достижимых маркировок.
6. **М6. Минимальная маркировка для срабатывания всех переходов** (2-2025, стр. 1–2; 13-2024, стр. 7). Покомпонентный максимум требований I(tj) по всем переходам (для параллельного срабатывания конфликтующих — сумма требований).
7. **М7. Матричный метод** (5-2025, стр. 1–3; 6-2025, с.1–2). (1) W⁻, W⁺ (n×m); (2) W=W⁺−W⁻; (3) µ0; (4) разрешённость: t_k ⇔ W⁻_k ≤ µ; (5) v(σ); (6) µ′ = µ0 + W·v(σ).
8. **М8. Приоритеты** (3-2025, стр. 3). Каждому переходу — Pr t; конфликт решается в пользу большего приоритета.
9. **М9. Временные сети** (3-2025, стр. 4). Задержка τ на дугах от переходов; метка доступна с t+τ; по умолчанию единичные.

(1) x1=y,…,xn=y^(n−1) ⇒ X′=FX+Bu, y=CX+Du; (2) X(t)=Φ(t,t0)X(t0)+∫_{t0}^t Φ(t,τ)Bu(τ)dτ, Φ(t)=e^{Ft}; (3) три метода расчёта e^{Ft}: степенной ряд (рекуррентно, ‖A_k‖<ε), возведение в квадрат (разбиение на 2^N частей), решение матричного ДУ (n столбцов); (4) НУ: СЛАУ CX0=y0, CFX0=y0′, …; (5) частотная область — М7.
