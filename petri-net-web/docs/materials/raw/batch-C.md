### TASK-C-01. Пример 11.1 — передаточная функция (РЕШЁН)
- Источник: [11-2025], стр. 8. (Дубликат: [11-12], стр. 7.)
- Цитата условия: «Пример 11.1. Найти передаточную функцию системы, заданной дифференциальным уравнением y'(t) + 5y(t) = x(t).»
- Дано: дифференциальное уравнение y'(t) + 5y(t) = x(t). Найти: передаточную функцию Φ(s).
- Ожидаемый формат ответа: формула Φ(s) (рациональная функция от s).
- Метод (по материалам): подстановка показательного воздействия (см. §6, метод 1).
- Полное решение (транскрипция слово в слово):
  - «Решение.»
  - x(t) = e^{st},
  - y(t) = Φ(s)e^{st}.
  - «Тогда»
  - y'(t) = Φ(s)se^{st}.
  - «Подставляя в дифференциальное уравнение, получаем:»
  - Φ(s)se^{st} + 5Φ(s)e^{st} = e^{st}.
  - «Отсюда»
  - Φ(s)(s + 5)e^{st} = e^{st}
  - «и»
  - Φ(s) = 1/(s + 5).
  - «Ответ: Φ(s) = 1/(s + 5).»

### TASK-C-03. Пример определения передаточной функции — общий случай ОДУ 2-го порядка (РЕШЁН)
- Источник: [11-2025], стр. 15. (Дубликат: [11-12], стр. 13.)
- Цитата условия: «Пример определения передаточной функции. Рассмотрим обыкновенное дифференциальное уравнение второго порядка a2y''(t) + a1y'(t) + a0y(t) = b1u'(t) + b0u(t).»
- Дано: ОДУ a2y''(t) + a1y'(t) + a0y(t) = b1u'(t) + b0u(t) (коэффициенты a2, a1, a0, b1, b0). Найти: передаточную функцию и частотную характеристику.
- Ожидаемый формат ответа: Φ(s) = (b1s + b0)/(a2s² + a1s + a0); Φ(iω) = (b1iω + b0)/(−a2ω² + a1iω + a0).
- Полное решение:
  - «Пусть u(t) = e^{st}. Тогда u'(t) = s·e^{st}.»
  - y(t) = Φ(s)·e^{st};
  - y'(t) = Φ(s)·s·e^{st};
  - y''(t) = Φ(s)·s²·e^{st}.
  - «Получаем:»
  - a2Φ(s)s²e^{st} + a1Φ(s)se^{st} + a0Φ(s)e^{st} = b1se^{st} + b0e^{st}.
  - (a2s² + a1s + a0)Φ(s)e^{st} = (b1s + b0)e^{st}.
  - «Φ(s) = (b1s + b0)/(a2s² + a1s + a0) — передаточная функция; при s = iω»
  - «Φ(iω) = (b1iω + b0)/(a2(iω)² + a1iω + a0) = (b1iω + b0)/(−a2ω² + a1iω + a0) — частотная характеристика.»

  - «Рассмотрим еще два конкретных примера для определения передаточной функции, а также частотной и фазовой характеристик.»

### TASK-C-04. Пример 11.3 «Гармонические колебания» (РЕШЁН)
- Источник: [11-2025], стр. 16. (Дубликат: [11-12], стр. 14.)
- Цитата условия: «Пример 11.3. Гармонические колебания. Гармонические колебания являются частным случаем апериодического звена при s = iω. А для апериодического звена имеет место следующая зависимость: Ty'(t) + y(t) = kx(t). Здесь k – коэффициент усиления, T – постоянная времени.»
- Дано: апериодическое звено Ty'(t) + y(t) = kx(t); s = iω. Найти: передаточную функцию, АЧХ, фазовую характеристику.
- Ожидаемый формат ответа: Φ(iω) в экспоненциальной форме; АЧХ = k/√(1+T²ω²); ФЧХ = arctg(Tω).
- Полное решение:
  - «Если x(t) = e^{st} и y(t) = Φ(s)e^{st},»
  - «То уравнение апериодического звена можно представить в виде»
  - TsΦ(s)e^{st} + Φ(s)e^{st} = ke^{st}.
  - «То есть Φ(s) = k/(Ts+1).»
  - «Тогда в случае гармонических колебаний получим передаточную функцию:»
  - Φ(iω) = k/(Tiω+1) = k(1−Tiω)/(T²ω²+1) = k·(1/√(1+T²ω²))·e^{−i·arctg(Tω)}.
  - «Коэффициент k/√(1+T²ω²) является амплитудной частотной характеристикой, а arctg Tω - фазовой характеристикой.»

### TASK-C-05. Пример 11.4 «Колебательное звено» (РЕШЁН)
- Источник: [11-2025], стр. 17. (Дубликат: [11-12], стр. 15.)
- Цитата условия: «Пример 11.4. Колебательное звено. Найдём передаточную функцию колебательного звена, система которого задаётся уравнением: T²y'' + 2Tξy' + y = kx(t), T > 0, 0 < ξ < 1. Здесь k – коэффициент усиления, T – постоянная времени, ξ – коэффициент колебаний.»
- Дано: ОДУ T²y'' + 2Tξy' + y = kx(t), T > 0, 0 < ξ < 1. Найти: Φ(s), Φ(iω), АЧХ, ФЧХ.
- Ожидаемый формат ответа: Φ(s) = k/(T²s²+2Tξs+1); АЧХ A(ω) = k/√((1−T²ω²)²+4T²ξ²ω²); ФЧХ φ(ω) = −arctg(2Tξω/(1−T²ω²)).
- Полное решение:
  - x(t) = e^{st}, y(t) = Φ(s)e^{st}, y'(t) = Φ(s)se^{st}, y''(t) = Φ(s)s²e^{st}.
  - T²Φ(s)s²e^{st} + 2TξΦ(s)se^{st} + Φ(s)e^{st} = ke^{st}.
  - Φ(s)(T²s² + 2Tξs + 1) = k.
  - Φ(s) = k/(T²s² + 2Tξs + 1).
  - «Положим s = iω.»
  - Φ(s) = k/(−T²ω² + 2Tξiω + 1) = k·(1−T²ω²−2Tξiω)/((1−T²ω²)²+4T²ξ²ω²).
  - «Амплитудно-частотная характеристика:» A(ω) = k/√((1−T²ω²)²+4T²ξ²ω²).
  - «Фазово-частотная характеристика:» φ(ω) = −arctg(2Tξω/(1−T²ω²)).

- **TASK-C-10. 5. Идеальное дифференцирующее звено.** (стр. 11) «Идеальный дифференциатор преобразует входную функцию x(t) = e^{st} в выход, равный y(t) = se^{st}. Следовательно, Φ(s) = s. - **TASK-C-11. 6. Идеальное интегрирующее звено.** (стр. 11) «Идеальный интегратор (s > 0) преобразует входной сигнал x(t) = e^{st} в выходной, равный y(t) = (1/s)e^{st}. Следовательно, Φ(s) = 1/s. Таким образом, идеальный интегратор даёт усиление гармонических колебаний обратно пропорционально частоте ω и отставание выходных колебаний по фазе π/2 независимо от частоты.»
- **TASK-C-12. 7. Форсирующее звено 1-го порядка.** (стр. 12) «При входном сигнале x(t) на выход поступает сигнал y(t) = k(Tx'(t) + x(t)). Тогда при x(t) = e^{st}, x'(t) = se^{st}, y(t) = k(Tse^{st} + e^{st}) = k(Ts + 1)e^{st}. И Φ(s) = k(Ts + 1).»
- **TASK-C-13. 8. Форсирующее звено 2-го порядка.** (стр. 12) «При входном сигнале x(t) на выход поступает сигнал y(t) = k(T²x''(t) + 2αTx'(t) + x(t)). - **TASK-C-14. 9. Апериодическое звено.** (стр. 13) «Для апериодического звена имеет место следующая зависимость: Ty'(t) + y(t) = kx(t). Если x(t) = e^{st}, y(t) = Φ(s)e^{st}, то TsΦ(s)e^{st} + Φ(s)e^{st} = ke^{st}. То есть Φ(s) = k/(Ts + 1).»
- **TASK-C-15. 10. Гармонические колебания.** (стр. 14) «Гармонические колебания являются частным случаем апериодического звена при s = iω. Здесь k – коэффициент усиления, T – постоянная времени. - **TASK-C-16. 11. Колебательное звено.** (стр. 14) «Найдём передаточную функцию колебательного звена, система которого задаётся уравнением: T²y'' + 2Tξy' + y = kx(t), T > 0, 0 < ξ < 1. Здесь k – коэффициент усиления, T – постоянная времени, ξ – коэффициент колебаний. x(t) = e^{st}, y(t) = Φ(s)e^{st}, y'(t) = Φ(s)se^{st}, y''(t) = Φ(s)s²e^{st}. Из определения эквивалентности следует: P = Po, W = Wo, s0 = s0o. … S = So и φ(si,pj) = φo(sio,pjо). … Если подставить это выражение для so(t+1) в функцию выхода автомата Мура, получим его определение через старое состояние: wko(t+1) = ψo(sko(t+1)) = ψo(φo(sio(t), pjo(t))), а так как φ(si,pj) = φo(sio,pjо), то для обеспечения условий эквивалентности необходимо выходные символы автомата Мили, получаемые на переходах в новые состояния, сделать равными выходным символам автомата Мура этих состояний и в результате получаем: wk(t+1) = ψ(si(t), pj(t)).»

## 6. Методы решения

1. **Определение передаточной функции методом показательного воздействия** — [11-2025], стр. 7–9, 15 (Примеры 11.1, 11.2 и общий пример 2-го порядка; дубликат [11-12], стр. 6–8, 13).
   Шаги: 1) задать x(t) = e^{st}; 2) искомую реакцию записать y(t) = Φ(s)e^{st} (тогда y^(n)(t) = Φ(s)s^n·e^{st}); 3) подставить в дифференциальное уравнение системы; 4) сократить общий множитель e^{st}; 5) выразить Φ(s) = отношение полиномов от s. Для ОДУ 2-го порядка a2y''+a1y'+a0y = b1u'+b0u результат: Φ(s) = (b1s+b0)/(a2s²+a1s+a0) (стр. 15).
