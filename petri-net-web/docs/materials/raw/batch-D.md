## 6. Методы решения

Все методы — как описаны в материалах партии (ссылки на файлы/страницы).

**Метод 1. Способы задания автомата без выходного преобразователя** — [13-2025(new)], стр. 7, 9–11.
1. Перечислением: все функции перехода sk = φ(si, pj) записываются равенствами (стр. 7).
2. Табличный: строится таблица переходов — «столбц ы которой помечаются входными символами, а строки – символами состояний, из которых осуществляется переход. Внутри таблицы на пересечении i -той строки и j-того столбца указывается состояние, в которое переходит автомат из состояния si под воздействием входного символа pj» (стр. 7; общий вид — табл. 1.1, стр. 8).
3. Графический: «каждому состоянию автомата ставится в соответствие вершина графа… вершины si и sj соединяются дугой, исходящей из si, а сама дуга помечается символом pk… граф автомата является ориентированным графом» (стр. 9; рис. 1.2, 1.3).

**Метод 2. Способы задания автомата Мура** — [13-2025(new)], стр. 14–16.
1. Перечислением: все функции перехода и выхода (s1 = φ(s0, p1), w1 = ψ(s1), …).
2. Табличный: таблица переходов «слева дополняется столбцом, в котором для каждого состояния sj указывается соответствующий ему выходной символ wj» (табл. 1.4, стр. 16).
3. Графический: вершина помечается «символом этого состояния si и выходным символом wi», дуга — символом входного символа pk (рис. 1.6, 1.7).

**Метод 3. Способы задания автомата Мили** — [14-2025(new)], стр. 1–3.
1. Перечислением: все функции перехода и выхода (w1 = ψ(s0, p1), …); «Функция перехода задается как в автомате Мура. Отличие состоит в задании функции выхода».
2. Табличный: отдельная таблица переходов (табл. 1.7) и «аналогичная ей таблица выходов (табл. 1.8), на пересечении i – той строки и j – того столбца которой указывается выходной символ wk, который выдает автомат при переходе из состояния si под воздействием входного символа pj»; обычно объединяются в «совмещенная таблица переходов и выхода (табл. 1.9)» — клетки «sj/wk».
3. Графический: вершина помечается si; «дуга помечается символом pk, под воздействием которого осуществляется данный переход, и выходным символом wq, который вырабатывается при этом переходе» (рис. 1.8, 1.9).

**Метод 4. Моделирование работы автомата (по тактам)** — [13-2025(new)], стр. 11 (табл. 1.3), стр. 19 (табл. 1.6); [14-2025(new)], стр. 4–5 (табл. 1.11).
1. Таблица по столбцам-тактам tk (t0…tn).
2. Автомат без выхода: состояние следующего такта sk(t+1) = φ(pi(t), sj(t)); ответ — последовательность состояний (табл. 1.3).
3. Автомат Мура: выход такта t+1 = ψ(состояние t+1); «В момент t0 значение wo* не учитывается, так как не является реакцией на входной символ, а определяется s0 – начальным состоянием автомата Мура еще до подачи на вход первого символа входной последовательности» (стр. 19).
4. Автомат Мили: выход определяется входным символом pi(t) и состоянием si(t) ТЕКУЩЕГО такта: Wk(t+1) = ψ(pi(t), sj(t)) — в таблице источник записывает выход со сдвигом на столбец (табл. 1.11: столбец t0 пуст).
5. Проверка эквивалентности на одном входе: одно и то же слово p1p2p2p1p2 → w0w1w0w0w0 у обоих типов (стр. 5 [14-2025(new)]).

**Метод 5. Построение автомата Мили, эквивалентного заданному автомату Мура** — [14-2025(new)], стр. 6–8.
1. Аналитически: P = Po, W = Wo, s0 = s0o; S = So; φ(si, pj) = φo(sio, pjo); функция выхода: «wk(t+1) = ψ(si(t) , pj(t))», т.е. выход Мили на переходе в новое состояние делают равным выходу Мура этого нового состояния (вывод через подстановку wko(t+1) = ψo(φo(sio(t), pjo(t))) — стр. 6–7).
2. Графически: «выходные символы, которыми помечены вершины графа автомата, перенести на все дуги, входящие в каждую вершину» (стр. 7; пример: рис. 1.10 → рис. 1.11, стр. 7–8).

**Метод 6. (Старая редакция [13-2024]) Построение и анализ сетей Петри** — [13-2024], стр. 1–7.
1. Построение графа по аналитическому заданию S = (P, T, I, O, µ): позиции p — круги, переходы t — палочки, дуга pi→tj кратности 1 на каждый элемент pi ∈ I(tj), tj→pi — на каждый элемент pi ∈ O(tj); метки — по µ (стр. 2, задания).
2. Разрешённость перехода: «Возникновение события в системе возможно, если выполняются определённые условия – предусловия собы тия» (стр. 1) — tj разрешён из µ, если для всех pi из I(tj) µ(pi) ≥ кратности pi в I(tj).
3. Срабатывание: «Возникновение события может привести к выполнению других условий – постусловий события» (стр. 1) — µ′(pi) = µ(pi) − кратность(pi, I(tj)) + кратность(pi, O(tj)).
4. Достижимость: «Маркировка µ′′ называется достижимой из маркировки µ′, если существует последовательность срабатывающих переходов…»; «Для доказательства недостижимости tj из маркировки µ, необходимо перебрать все последовательности переходов, срабатывание которых переводит сеть из µ в µ ′′» (стр. 1).
5. Классификация по определениям стр. 3 (живая/тупиковая/частичнотупиковая), стр. 5 (k-ограниченная), стр. 6 (безопасная, «Очевидно, что безопасная цепь Петри является сетью ограниченной с k=1», консервативная — «сумма меток во всех позициях постоянна… количество меток на входе каждого перехода равно количеству меток на выходе»).
6. Минимальная маркировка для срабатывания всех переходов (Задание 5, стр. 7): покомпонентный максимум кратностей I(tj) по всем tj.

**Метод 7. (Старая редакция [13-14]) Метод пространства состояний для ЛНС** — [13-14], стр. 6–21.
1. Представление ОДУ n-го порядка Σa_i·y^(i)(t) = Σb_j·x^(j)(t) системой 1-го порядка: вводят переменные состояния x1=y, x2=y′, …, xn=y^(n−1); получается X′ = FX + Bu, y = CX + Du (уравнение динамики / уравнения выхода; стр. 6–9).
2. Полное решение во временной области (стр. 9–12): суперпозиция X(t) = Xo(t) + Xч(t); Xo(t) = e^{Ft}C, с начальными условиями Xo(t) = Φ(t,t0)X(t0), где Φ(t) = e^{Ft} — фундаментальная матрица; Xч(t) = ∫_{t0}^{t} Φ(t,τ)Bu(τ)dτ; полное решение X(t) = Φ(t,t0)X(t0) + ∫_{t0}^{t} Φ(t,τ)Bu(τ)dτ; подстановка в y = CX + Du.
3. Три метода расчёта фундаментальной матрицы (стр. 11–14):
   - 1-й: суммирование матричного степенного ряда через рекуррентные соотношения A0 = E, A_{i+1} = (Ft/(i+1))A_i (без многократного возведения F в степени и факториалов); остановка, когда каноническая норма ||A_k|| < ε; для равноотстоящих узлов — Φ(tj+1) = Φ(tj)e^{FH}.
   - 2-й (улучшенный): отрезок [0,H] разбивают на 2^N частей h = H/2^N так, чтобы e^{Fh} вычислялось ≤3 членами ряда; φ0 = e^{Fh}, φ_{k+1} = φ_k², e^{FH} = (e^{Fh})^{2^N} — многократное возведение в квадрат.
   - 3-й: Φ(t) как решение матричного ДУ: «Правильно выбирая вектор начальных условий, можно последовательно определять вектор -столбцы фундаментальной матрицы Φ(t)… решение дифференциального уравнения динамики ровно n раз позволяет последовательно определить столбцы фундаментальной матрицы» (X0 = (0,…,0,1,0,…,0)^T).
4. Определение начальных условий переменных состояния по начальным условиям ОДУ (стр. 16–17): из y(t) = CΦ(t)X0 при t=0 с производными Φ(k)(0) = F^k получают СЛАУ: CX0 = y0, CFX0 = y0′, …, CF^{n−1}X0 = y0^{(n−1)} (Пример 2 для n=2).
5. Решение в частотной области (стр. 18–21): преобразование Лапласа обеих частей: sX_L(s) − X(0) = FX_L(s) + Bu_L(s) ⇒ X_L(s) = (sE−F)⁻¹Bu_L(s) + (sE−F)⁻¹X(0); y_L(s) = C(sE−F)⁻¹X(0) + C(sE−F)⁻¹Bu_L(s) + Du_L(s); обратную (sE−F)⁻¹ ищут как решение (sE−F)(sE−F)⁻¹ = E (по СЛАУ на столбцы); первое слагаемое y_L — переходный процесс (от начальных условий), второе — вынужденное движение (Пример 3: полный расчёт до W(s) = (s+2)/(s²+3s+2) и СЛАУ для X(0)).
