- с.5: система линейных алгебраических уравнений для c_1..c_n из начальных условий; определение y_ч(t) (реакция при нулевых НУ на вход x(t)); Таблица 2 (входное воздействие → вид частного решения); ЗАДАНИЕ — «Определить выходные сигналы y(t)» (5 ОДУ с начальными условиями).

- с.13: ЗАДАНИЕ — 2 пункта: 1) весовая функция ẏ(t)−8y(t)=x(t); 2) весовая функция апериодического звена Ty'(t)+y(t)=kx(t), y(0)=y_0, T,k=const. Решений в файле НЕТ.

  > P = {p1, p2, p3},

  > I(t1) = {p1, p3}, O(t1) = {p3},

  > μ = (2,1,1).

  > • Для исходного состояния системы определить, возможно ли срабатывание переходов в последовательности: t1 → t1 → t2 → t2.
  > • Для исходного состояния системы определить состояние системы после срабатывания переходов в последовательности: t2 → t1 → t1.

- Ожидаемый формат ответа: вычисления по матричной модели — разрешённость (да/нет с обоснованием по позициям), векторы маркировок после каждого шага последовательности, итоговый вектор μ′.
- Метод (по материалам): матричный способ представления сети Петри (титул с.1); формализм — аналитическая 5-ка S=(P,T,I,O,μ) и последовательности срабатываний.

    - t2: I(t2)={p1}, O(t2)={p3};
    - t3: I(t3)={p2, a}, O(t3)={p4};

- Полное решение (транскрипция построчно):
  1. Чтобы найти весовую функцию системы надо в качестве входного сигнала использовать единичную импульсную δ-функцию: x(t) = δ(t − τ). Тогда выходным сигналом будет весовая функция: y(t) = g(t, τ).
  2. Тогда дифференциальное уравнение имеет вид: ḡ(t, τ) + 5g(t, τ) = δ(t − τ).
  3. Данное дифференциальное уравнение является неоднородным дифференциальным уравнением 1-ого порядка.
  4. На первом этапе необходимо решить соответствующее однородное дифференциальное уравнение:
     - ḡ(t, τ) + 5g(t, τ) = 0.
     - ḡ + 5g = 0
     - ḡ = −5g
     - dg/dt = −5g
     - dg/g = −5dt
     - ∫(dg/g) = ∫(−5dt)
     - ∫(dg/g) = −5∫dt
     - ln g = −5t + C₁, где C₁ = const.
     - g = e^{−5t+C₁} = e^{C₁}e^{−5t} = Ce^{−5t}, где C = e^{C₁} = const.
     - Однородное дифференциальное уравнение решено.
  5. Неоднородное дифференциальное уравнение решается методом вариации постоянной: C = C(t).
     - g = C(t)e^{−5t}.
     - ḡ = Ċ(t)e^{−5t} − 5C(t)e^{−5t}.
     - Тогда неоднородное дифференциальное уравнение имеет вид: Ċ(t)e^{−5t} − 5C(t)e^{−5t} + 5C(t)e^{−5t} = δ(t − τ).
     - Ċ(t)e^{−5t} = δ(t − τ)
     - (dC/dt)e^{−5t} = δ(t − τ)
     - dC = e^{5t}δ(t − τ)dt
     - C(t) = ∫_{−∞}^{∞} e^{5t}δ(t − τ)dt
     - C(t) = e^{5τ}
     - g(t, τ) = e^{5τ}e^{−5t} = e^{−5(t−τ)}.
- Ответ (цитата):
  > Ответ: весовая функция системы g(t, τ) = e^{−5(t−τ)}.

### EX-B-10 [РШ] — Весовая функция идеального интегрирующего звена (семинар 10)

### EX-B-11 [РШ] — Пример 2. Весовая функция системы «двигатель» и стационарность (семинар 10)
- Источник: B5 `Семинар МИПиС-10-2025(new).pdf`, с.8–10.
- Условие (цитата):
  > Пример 2. Найти весовую системы, состоящей из двигателя, у которого входным сигналом является вращающий момент M, выходным сигналом угловая скорость вращения вала ω, сопротивление вращающегося вала пропорционально угловой скорости. Момент инерции вала J=const. Определить, является ли система стационарной.
- Полное решение (транскрипция построчно):
  1. Система описывается дифференциальным уравнением
     Jω̇ = M − hω,
     где hω — момент сил сопротивления.
  2. Для нахождения весовой функции необходимо на вход подать единичную импульсную δ-функцию: M = δ(t − τ).
  3. Тогда выходным сигналом будет искомая весовая функция: ω = g(t, τ).
  4. Дифференциальное уравнение примет вид: Jḡ = δ(t − τ) − hg. Или: Jḡ + hg = δ(t − τ).
  5. Решим однородное дифференциальное уравнение
     Jḡ + hg = 0
     ḡ = −(h/J)g
     dg/dt = −(h/J)g
     dg/g = −(h/J)dt
     ∫(dg/g) = ∫(−(h/J)dt)
     ∫(dg/g) = −(h/J)∫dt
     ln g = −(h/J)t + C₁, где C₁ = const.
     g = e^{−(h/J)t+C₁} = e^{C₁}e^{−(h/J)t} = Ce^{−(h/J)t}, где C = e^{C₁} = const.
     Однородное дифференциальное уравнение решено.
  6. Неоднородное дифференциальное уравнение решается методом вариации постоянной: C = C(t).
     g = C(t)e^{−(h/J)t}.
     ḡ = Ċ(t)e^{−(h/J)t} − (h/J)C(t)e^{−(h/J)t}.
  7. Тогда неоднородное дифференциальное уравнение имеет вид:
     JĊ(t)e^{−(h/J)t} − J(h/J)C(t)e^{−(h/J)t} + hC(t)e^{−(h/J)t} = δ(t − τ).
     JĊ(t)e^{−(h/J)t} = δ(t − τ)
     (dC/dt)Je^{−(h/J)t} = δ(t − τ)
     dC = (1/J)e^{(h/J)t}δ(t − τ)dt
     C(t) = ∫_{−∞}^{∞} (1/J)e^{(h/J)t}δ(t − τ)dt
     C(t) = (1/J)e^{(h/J)τ}
     g(t, τ) = (1/J)e^{(h/J)τ}e^{−(h/J)t} = (1/J)e^{−(h/J)(t−τ)}.
  8. Так как весовая функция системы зависит только от разности (t − τ), то система является стационарной.
- Ответ (цитата):
  > Ответ: весовая функция системы g(t, τ) = (1/J)e^{−(h/J)(t−τ)}.
  > Система стационарная.

### EX-B-12 [РШ] — Весовая функция колебательного звена (семинар 10)
- Источник: B5 `Семинар МИПиС-10-2025(new).pdf`, с.11–12.
- Условие (цитата):
  > Колебательное звено
  > Найдём весовую функцию колебательного звена, система которого задаётся уравнением:
  > T²y'' + 2Tξy' + y = ku(t), T > 0, 0 < ξ < 1.
  > Здесь k – коэффициент усиления, T – постоянная времени, ξ – коэффициент колебаний.
- Полное решение (транскрипция построчно):
  1. Дифференциальное уравнение второго порядка решается с помощью характеристического уравнения.
  2. Для однородного дифференциального уравнения
     T²y'' + 2Tξ + y = 0   [в оригинале в среднем члене опечатка — напечатано «2Tξ» без y'; из характеристического уравнения ниже видно, что имеется в виду T²y''+2Tξy'+y=0]
     характеристическое уравнение имеет вид:
     T²λ² + 2Tξλ + 1 = 0
     λ² + 2(ξ/T)λ + 1/T² = 0.
     λ = −ξ/T ± √(ξ²/T² − 1/T²) = −ξ/T ± i·√(1−ξ²)/T.
  3. Обозначим α = −ξ/T, ω = √(1−ξ²)/T. Тогда λ = α ± iω. И фундаментальная система решений имеет вид:
     y_1(t) = e^{αt}cos ωt, y_2(t) = e^{αt}sin ωt.
  4. Решением однородного уравнения является функция
     y(t) = e^{αt}(C₁ cos ωt + C₂ sin ωt).
  5. Весовая функция g(t) определяется как y_0(t) с начальными условиями g(0) = 0, g'(0) = 1/T².
  6. g(t) = e^{αt}(C₁ cos ωt + C₂ sin ωt).
     g(0) = C₁ = 0.
     g'(t) = αe^{αt}C₂ sin ωt + C₂e^{αt}ω cos ωt.
     g'(0) = C₂ω = 1/T².
     C₂ = 1/(T²ω) = 1/(T√(1−ξ²)).
     g(t) = 1/(T√(1−ξ²))·e^{−ξt/T}·sin(√(1−ξ²)/T·t).
  7. Таким образом, весовая функция колебательного звена равна
     g(t) = 1/(T√(1−ξ²))·e^{−ξt/T}·sin(√(1−ξ²)/T·t).
- Ответ: g(t) = 1/(T√(1−ξ²))·e^{−ξt/T}·sin(√(1−ξ²)·t/T).

## 4. Глоссарий (термин → определение слово в слово + файл/страница)

То есть для каждой вычислимой функции существует вычисляющий её элемент или программа, а все функции, вычисляемые множеством вычислител ей, являются вычислимыми функциями.» (B2, с.1)

Данная функция линейной системы представляет собой реакцию этой системы в момент t на единичный импульс, действующий на систему в момент τ, и обозначается g(t,τ).» (B5, с.1)

21. **Живая / тупиковая / безопасная / ограниченная / консервативная сеть** — термины в вопросе задачи: «Указать будет ли сеть живой или тупиковой, безопасной или ограниченной, консервативной.» (B1, с.2); формальные определения — в партии A (классификация сетей Петри).
22. **Команды машины Минского** — «1. i : Inc a, k — увеличивает значение регистра a на единицу и переходит к выполнению k-ой команды; 2. i : Dec a, k, l — если значение регистра a не равно нулю, то это значение уменьшается на единицу и выполняется переход к k-ой команде, в противном случае производится переход к l-ой команде; 3. i : Halt — команда останова.» (B2, с.1)
23. **Входное/выходное воздействие** — пары «Входное воздействие x(t)» / «Выходное воздействие y_ч(t)» в Таблице 2 (B4, с.5); частное решение y_ч(t): «Основавается на идеологии исследования линейных систем и заключается в изучении реакции системы при нулевых начальных условиях при предъявлении на вход системы определенного входного воздействия x(t) и реализации этапов, описанных в начале данной лекции. Исходим из соображений, что характер входного воздействия не изменяется.» (B4, с.5)

## 6. Методы решения

### М1. Матричный способ представления сетей Петри (B1, с.1–2)
Как дают в материалах: сеть задана аналитически 5-кой S=(P,T,I,O,μ); требуется «представить сеть Петри в матричном виде» (TASK-B-2) и «используя матричную модель сети Петри» проверять разрешённость (TASK-B-1).
Шаги (стандартный формализм матричной модели, на который указывают задачи):
1. Построить входную матрицу I (|P|×|T|), выходную матрицу O (|P|×|T|) по множествам I(t), O(t) (повтор позиции = вес); инцидентная матрица C = O − I.
2. Разрешённость перехода t в маркировке μ: для всех p ∈ I(t) — μ(p) ≥ веса входящих дуг (компонентно μ ≥ I[:, t]).
3. Срабатывание t: μ′ = μ + C[:, t] (т.е. μ′ = μ − I[:,t] + O[:,t]); проверка возможности последовательности t1→t2→… шаг за шагом (TASK-B-1б, TASK-B-2в).
4. Маркировка после последовательности: итерация шага 3 (TASK-B-2в, TASK-B-3в).

### М2. Построение сети по аналитическому описанию + минимальная маркировка + свойства (B1, с.2, TASK-B-3)
1. «Построить данную сеть» — граф из P, T, дуг с весами (повтор позиции в I/O = вес дуги: I(t1)={p1,p1,p3} ⇒ дуга p1→t1 веса 2).
2. Минимальная маркировка, при которой сеть сработает — минимальный μ, разрешающий (последовательное) срабатывание переходов (оценка по весам входящих дуг с учётом пополнений выходами).
3. Свойства: живая/тупиковая (существование/отсутствие тупиковых маркировок), безопасная (μ(p)≤1 во всех достижимых)/ограниченная (μ(p)≤K), консервативная (сумма меток инвариантна) — анализ по графу достижимости/инвариантам (термины из партии A).

### М3. Моделирование информационных систем сетями Петри (B2 с.5, B3 с.1)
Приём (по задачам): сущности (заказы, сотрудники, файлы, светофоры, комнаты) — позиции; действия/события (выполнить заказ, получить файл, перейти к фазе) — переходы; ограничения по ресурсам — позиции с фиксированным числом меток (светофор/мьютекс: ванная — 1 метка, «слоты» сотрудника — 2 метки); ветвления и циклы (в т.ч. возврат на переделку) — развилки/схождения переходов; длительности в тактах — счётчики тактов (TASK-B-9). Результат — граф + (где требуется) аналитическая модель.

### М4. Кодирование программы машины Минского сетью Петри (B2, с.2–4; EX-B-1…EX-B-3)
Общие правила: позиции двух типов — регистры (число меток = значение регистра) и команды (текущая команда = позиция с 1 меткой, остальные пусты).
1. Команда `i : Inc a, k` — один переход t: I(t)={i}, O(t)={a,k}.
2. Команда `i : Dec a, k, l` — пять переходов: t1: I={i}, O={p1,p2}; t2: I={p1}, O={p3}; t3: I={p2,a}, O={p4}; t4: I={p3,p2}, O={l}; t5: I={p4}, O={k}. a непусто ⇒ t1,t2,t3,t5 (переход в k, a−=1); a пусто ⇒ t1,t2,t4 (переход в l).
3. Команда `i : Halt` — один переход t: I(t)={i}, O(t)=∅ (метка поглощается).
Вывод материала: сети с максимальным параллелизмом полны по Тьюрингу (B2, с.1).

### М5. Опредeление весовой функции ЛНДС через операторы (B4, с.2)
«Перечислим основные этапы определения весовой функции g_y(t,τ) системы:
1. Для системы (9.1) (она не выполняет дополнительного преобразования входного воздействия) определить весовую функцию g_z(t,τ), положив x(t) = δ(t − τ).
2. Применить оператор правой части к g_z(t,τ): g_y(t,τ) = D_2 g_z(t,τ).
Таким образом, вместо изучения системы (9.1) достаточно изучить систему (9.2).» (B4, с.2)
Практический частный случай (B5, с.1): если известна зависимость «вход-выход», взять x(t)=δ(t−τ), тогда y(t)=g(t,τ).

### М6. Решение ОДУ с начальными условиями (B4, с.3–5) — для TASK-B-10…B-14
1. Полное решение y(t) = y_о(t) + y_ч(t): y_о — общее решение однородного (9.4) с заданными НУ, y_ч — частное решение неоднородного с нулевыми НУ.
2. Однородное: характеристическое уравнение P_n(s)=Σa_i s^i=0 (9.5); по Таблице 1 (B4, с.4) — набор решений по типам корней (вещественный кратности 1: e^{st}; кратности k: e^{st}, te^{st}, …, t^{k−1}e^{st}; комплексно-сопряжённый α±iω кратности 1: e^{αt}cosωt, e^{αt}sinωt; кратности k (2k≤n): e^{αt}cosωt, te^{αt}cosωt, …, t^{k−1}e^{αt}cosωt, e^{αt}sinωt, te^{αt}sinωt, …, t^{k−1}e^{αt}sinωt). y_0(t)=Σc_i y_i(t).
3. Частное по Таблице 2 (B4, с.5): x(t)=e^{αt} ⇒ y_ч=Ce^{αt}; x(t)=sin αt (в оригинале «sin αx») или cos αt ⇒ y_ч=A sin αt + B cos αt; x(t)=Σa_i t^i (в оригинале «x^i») ⇒ y_ч=Σb_i t^i.
4. Постоянные c_i — из системы ЛАУ (B4, с.5): подстановка y(t_0)=y_0, y′(t_0)=y′_0, …, y^{(n−1)}(t_0)=y_0^{(n−1)} в y_о и его производные.

### М7. Метод вариации постоянной для уравнений с δ-входом (B5, с.2–10) — для EX-B-4, EX-B-11, TASK-B-15…B-16
Пошаговый шаблон (как в Примерах 1 и 2):
1. Подставить x(t)=δ(t−τ), y(t)=g(t,τ).
2. Решить однородное: для ġ+ag=0 — разделение переменных: dg/g=−a dt ⇒ g=Ce^{−at} (a=5 — Пример 1; a=h/J — Пример 2; a=−8 — TASK-B-15).
3. Вариация постоянной C=C(t): подставить g=C(t)e^{−at} в неоднородное ⇒ Ċ(t)e^{−at}=δ(t−τ) (слагаемые с C сокращаются).
4. dC=e^{at}δ(t−τ)dt ⇒ C(t)=∫_{−∞}^{∞} e^{at}δ(t−τ)dt = e^{aτ} (свёртывающее свойство, B4 с.7).
5. g(t,τ)=e^{aτ}e^{−at}=e^{−a(t−τ)} (Пример 2: с множителем 1/J).
6. Стационарность: g зависит только от (t−τ) ⇒ система стационарна (B5, с.10).

### М8. Весовая функция колебательного звена (B5, с.11–12) — EX-B-12
1. Однородное T²y''+2Tξy'+y=0; характеристическое λ²+2(ξ/T)λ+1/T²=0; корни λ=−ξ/T±i√(1−ξ²)/T=α±iω.
2. Фундаментальная система: y_1=e^{αt}cosωt, y_2=e^{αt}sinωt; y(t)=e^{αt}(C₁cosωt+C₂sinωt).
3. Весовая функция g(t) определяется как y_0(t) с начальными условиями g(0)=0, g'(0)=1/T² (следствие из T²g''+2Tξg'+g=δ(t): g(0)=0, T²g'(0)=1).
4. C₁=g(0)=0; C₂ω=g'(0)=1/T² ⇒ C₂=1/(T²ω)=1/(T√(1−ξ²)).
5. g(t)=1/(T√(1−ξ²))·e^{−ξt/T}·sin(√(1−ξ²)/T·t).

### М9. Вывод весовых функций идеальных систем (B5, с.4–7) — EX-B-5…EX-B-10
Единый приём: «Для того, чтобы найти весовую функцию системы, следует подать на вход системы δ-функцию», затем подставить x(t)=δ(t−τ) в закон y(t)=…:
1. тождественное: g=δ(t−τ); 2. экстраполятор: g=δ(t−(τ−a)); 3. запаздывающее: g=δ(t−(τ+a)); 4. усилитель: g=k(t)δ(t−τ); 5. дифференцирующее: g=δ'(t−τ); 6. интегрирующее: g=∫_{t_0}^{t}δ(σ−τ)dσ=1(t−τ). Вывод: все идеальные линейные системы стационарны.
